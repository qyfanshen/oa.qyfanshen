# Quick Start

## 5 分钟跑起来

### 1. 克隆

```bash
git clone https://gitee.com/qyfanshen/oa.qyfanshen.git
cd oa.qyfanshen.com
```

### 2. 环境准备

- Node.js ≥ 18，pnpm ≥ 8

### 3. 启动

```bash
pnpm install
pnpm dev
# → http://localhost:3000
```

### 4. 下一步

- 阅读 [`ARCHITECTURE.md`](ARCHITECTURE.md) 了解系统设计
- 阅读 [`DEPLOYMENT.md`](DEPLOYMENT.md) 部署到生产环境
- 阅读 [`API.md`](API.md) 查看接口文档
